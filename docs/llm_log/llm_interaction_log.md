- Дата: 29 жовтня 2026 р.

- Параметри: temperature і seed не застосовуються, поведінка детермінована.
- Версії підказки: V1 (базова) і V2 (покращена), описані в docs/t2s_eval.md.
- Сирий вихід: llm_log/t2s_execution_log.json, поле raw_response для кожного з 18 питань.
- Рішення людини: метрики 88.9%, 44.4%, 88.9% для V1 та 100%, 50.0%, 100% для V2 прийнято; п'ять помилок класифіковано в docs/t2s_eval.md.

## Декларація використання генеративного ШІ

1. Інструмент: Claude Sonnet 5.5 (Anthropic).
2. Призначення: підготовка чернеток документів звіту, README та таблиці тверджень; повторний запуск скриптів для відтворення результатів.
3. Приклад запиту: «згенеруй і надішли окремими файлами .md які вимагаються в цій роботі».
4. Як перевірено: результати SPARQL-запитів, звіти pySHACL та метрики text-to-SPARQL відтворено повторним запуском скриптів на data/kb.ttl і порівняно з логами.
5. Відповідальність: автор роботи відповідає за кожне твердження і може пояснити та змінити будь-який запит чи фрагмент коду.
