# Результат 1. RDF-дані у триплстор. Журнал завантаження

Артефакти: data/kb.ttl, data/kb_sample.jsonld, docs/load_log.md.
Предметна область: моніторинг пацієнтів (Patient Monitoring). Базовий простір імен: http://www.semanticweb.org/patient_monitoring#

## Версія та дата

- Дата завантаження й перевірки: 28 жовтня 2026 р.
- Версія датасету: v1.0.
- Python 3.12.6, rdflib 7.6.0, pyshacl 0.40.1.
- Сховище: rdflib.Graph (внутрішньопам'ятне сховище).
- Контрольна сума SHA-256 файлу data/kb.ttl починається з 6dfc4a739a1965d1.

## Крок 1. Експорт у Turtle та збагачення даними

Онтологію з файлу data/onto.owl (115 триплетів) та індивідів з файлу data/onto_data.ttl (82 триплети) об'єднано в один граф (197 триплетів). Далі скрипт scripts/step1_autogen.py додав 200 триплетів: для кожного i від 1 до 29 створюється пацієнт :patient_NN, пристрій :dev_device_NN з ідентифікатором DEV-ID-NNN, зв'язок :isMonitoredBy, показник життєдіяльності :vital_sign_NN та його числове значення :hasValueNumeric (120 + i).

Підсумковий граф збережено у data/kb.ttl: 397 триплетів, 166 різних суб'єктів, зокрема 29 пацієнтів, 29 медичних пристроїв, 29 показників життєдіяльності, 38 класів, 11 об'єктних і 5 даних-властивостей.

## Крок 2. Завантаження та префікси

Граф завантажено командою Graph().parse("data/kb.ttl", format="turtle"). Файл розібрано без помилок, граф валідний.

Префікси в шапці файлу: порожній префікс (:) для простору імен проєкту, а також owl, rdfs, rdf, xsd, skos. Ті самі префікси й простір імен використано в запитах, формах SHACL та файлі зв'язків.

## Крок 3. Перевірка кількості триплетів

Запит:

```sparql
SELECT (COUNT(*) AS ?count) WHERE { ?s ?p ?o }
```

Результат: count = 397. Значення збігається з len(g), вимога щодо не менш ніж 300 триплетів виконана.

## Крок 4. JSON-LD

Файл data/kb_sample.jsonld створено командою serialize(format="json-ld"). Він містить масив із 20 вузлів з окремими ідентифікаторами (@id), зокрема пацієнтів, пристрої, показники, відгуки та сутності онтології. Файл читається назад rdflib без помилок.

## Висновок

Граф знань містить 397 триплетів, валідний, завантажений у сховище й підтверджений запитом COUNT. Префікси узгоджені, зазначено версію та дату завантаження, підготовлено JSON-LD для 20 сутностей.
