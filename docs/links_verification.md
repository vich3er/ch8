# Результат 5. Зв'язки з відкритими графами

Артефакти: data/links.ttl, scripts/verify_links.py, docs/links_verification.md.
Зовнішній граф: Wikidata (http://www.wikidata.org/entity/). Використано предикат skos:exactMatch, кожен зв'язок має коментар rdfs:comment із рівнем впевненості.

## Кроки 1 і 2. Знайдені відповідники

Зіставлення виконано за назвою поняття та його атрибутами (місце в ієрархії онтології, призначення).

1. :BloodPressure відповідає wd:Q851352 (артеріальний тиск; у онтології підклас :VitalSign). Впевненість: висока.
2. :HeartRate відповідає wd:Q189394 (частота серцевих скорочень; у онтології підклас :VitalSign). Впевненість: висока.
3. :PulseOximeter відповідає wd:Q1417535 (пульсоксиметр, прилад вимірювання насичення крові киснем). Впевненість: висока.
4. :OxygenSaturation відповідає wd:Q2065809 (насичення киснем; у онтології підклас :VitalSign). Впевненість: висока.
5. :BodyTemperature відповідає wd:Q332212 (температура тіла). Впевненість: середня-висока.

Усі п'ять зв'язків записано у файлі data/links.ttl.

## Крок 3. Верифікація та відхилений зв'язок

Кожен зв'язок оцінено за співпаданням назви, опису та місця поняття в ієрархії (рівень верифікації V1).

Відхилено зв'язок: :WearableSensor skos:exactMatch wd:Q1802188.

Обґрунтування: wd:Q1802188 позначає загальну категорію «Wearable technology» (носимі технології), яка охоплює годинники, окуляри, одяг та інші пристрої, а не конкретний вимірювальний сенсор. Відношення exactMatch означало б взаємозамінність понять, тому зв'язок відхилено. У файлі links.ttl його залишено закоментованим разом із поясненням.

## Крок 4. Federated-запит

Запит зі скрипта scripts/verify_links.py з'єднує локальні поняття із Wikidata через зв'язки skos:exactMatch і отримує англомовні назви понять:

```sparql
PREFIX skos: <http://www.w3.org/2004/02/skos/core#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT ?localConcept ?wdConcept ?wdLabel WHERE {
    ?localConcept skos:exactMatch ?wdConcept .
    SERVICE <https://query.wikidata.org/sparql> {
        ?wdConcept rdfs:label ?wdLabel .
        FILTER(LANG(?wdLabel) = "en")
    }
}
LIMIT 10
```

Запуск: python scripts/verify_links.py. Запит використовує змінну ?wdConcept і в локальній, і у віддаленій частині, тому результатом є назви саме тих сутностей Wikidata, на які вказують зв'язки з файлу links.ttl.

## Висновок

Для п'яти понять онтології встановлено зв'язки з Wikidata з коментарями про рівень впевненості, один зв'язок відхилено з поясненням, federated-запит використовує встановлені зв'язки.
